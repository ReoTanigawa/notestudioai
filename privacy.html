NoteStudioAI プライバシーポリシー

NoteStudioAI（以下「本アプリ」）は、YouTubeチャンネル「ただの車好きシュウ」の運営者が、自分のチャンネルに動画を投稿するためだけに使う個人用のツールです。一般の利用者向けには提供していません。

1. 取得する情報

本アプリは、運営者本人のGoogleアカウントで許可を受け、YouTube Data API の「動画のアップロード」の権限（youtube.upload）だけを使います。運営者以外の人の個人情報は取得しません。

2. 情報の使い方

許可によって得たアクセス情報は、運営者自身のチャンネルへの動画・サムネイルのアップロードにのみ使います。広告や分析、第三者への提供には使いません。

3. 保存と管理

アクセス情報は運営者のパソコン内にのみ保存し、外部のサーバーには送りません。Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

4. Googleのサービスについて

本アプリは YouTube API Services を利用しています。YouTubeの利用規約（https://www.youtube.com/t/terms）と、Googleのプライバシーポリシー（https://policies.google.com/privacy）が適用されます。
